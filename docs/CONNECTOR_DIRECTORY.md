# MCP connector directory

Vendor sources checked 2026-11-18. This is a curated, extensible inventory, not an exhaustive global list or a claim of tested Argos compatibility. See [setup and limits](COMPANY_CONNECTORS.md). BonDossier is a RavioleLabs first-party integration; its endpoint was cross-checked against the read-only BonDossier source, not a completed live account test.
